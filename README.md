# GlassDesk 更新

[下载 GlassDesk 1.0.1](https://github.com/everlosttime/glassdesk-updates/releases/tag/v1.0.1)

1.0.1 修复图标外围黑底：圆角图标之外使用透明背景，程序、窗口、托盘和安装包标识统一。安装包为桌面和开始菜单快捷方式指定版本化图标文件，避免使用旧缓存。

此仓库提供公开安装包、SHA256SUMS.txt 和更新说明。0.2.9 及之后的安装版可在关于页检查更新；1.0.0 可以升级到本修正版。升级保留配置、应用库、布局和图标缓存。

适用于 Windows 11 Build 26100 x64，内置 .NET 10 运行时，安装包未签名。
