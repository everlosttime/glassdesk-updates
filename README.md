# GlassDesk 更新

[下载 GlassDesk 1.0.2](https://github.com/everlosttime/glassdesk-updates/releases/tag/v1.0.2)

1.0.2 将启动台上一页和下一页改为无边框小箭头，并加入约 240 毫秒的横向滑动：下一页向左滑，上一页向右滑，搜索框和页码保持固定。支持连续反向翻页、搜索中断和减少动画设置。保留透明圆角应用图标。

此仓库提供公开安装包、SHA256SUMS.txt 和更新说明。0.2.9 及之后的安装版可在关于页检查更新；1.0.1 可以升级到此版本。升级保留配置、应用库、布局和图标缓存。

适用于 Windows 11 Build 26100 x64，内置 .NET 10 运行时，安装包未签名。
