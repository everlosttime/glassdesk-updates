# GlassDesk 公开更新

## 最新版本：GlassDesk 1.6.0

本版新增公历 / 农历切换和官网二维码下载入口，完善信息栏外设电量摘要及离线读取组件，修复快捷键打开启动台时的整页虚线框，并包含 1.5.11、1.5.12 的背景读取与玻璃滤镜优化。可选奶蛙回收站由设置管理，默认关闭。

适用于 Windows 10 Build 19041 及以上、Windows 11 的 x64 系统，安装包自带 .NET 10。覆盖升级保留现有设置、应用库、布局和自定义图标。
