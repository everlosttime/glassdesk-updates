# GlassDesk 公开更新

## 最新版本：GlassDesk 1.5.0

本版新增启动台分组，整合 Windows 10 兼容、图标显示修复，以及覆盖升级和自定义安装位置选择。

- 启动台支持分组筛选、编辑成员、组内搜索和平铺排序，保留文件夹模式。
- 新资料默认分组、空心启动台图标及高刷新选项；已有明确保存的选择保持不变。
- 支持 Win10 Build 19041 及以上，修复部分 ICO 图标在 Dock 和启动台显示成文件类型图标的问题。
- 信息栏实时网速默认关闭，支持应用音量控制；托盘图标支持注册恢复。
- 安装时可选择覆盖升级或自定义位置；覆盖升级保留设置、应用库、布局和自定义图标。
- 更新继续通过夸克或百度网盘手动下载，本版未加入扫码更新。
