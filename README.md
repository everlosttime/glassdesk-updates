# GlassDesk 更新

[下载 GlassDesk 1.3.6](https://github.com/everlosttime/glassdesk-updates/releases/tag/v1.3.6)

1.3.6 更新：

- 全新玻璃质感软件图标，统一程序、托盘、安装器和快捷方式。
- 启动台“添加”菜单新增“从桌面批量添加…”，支持多选、全选及清空选择。
- 添加程序及快捷方式时优先使用 Windows 本地化显示名称，修复部分名称显示为英文的问题。
- 外观设置支持独立调节 Dock 常驻图标和启动台文字的黑白亮度，并可自由选择启动台图标实心或空心。
- 桌面图标显隐按钮中的两个小方块改为实心。

升级保留设置、布局、应用库、用户自定义图标及启动配置，包含此前版本的图标兼容与玻璃背景修复。

此仓库提供公开安装包、SHA256SUMS.txt 和更新说明。设置 → 关于 → 检查更新可获取最新稳定版；安装包不包含用户 Data。适用于 Windows 11 x64 Build 22000 及以上，内置 .NET 10。
